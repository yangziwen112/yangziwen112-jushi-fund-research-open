# 聚势基金研究项目 Constitution

## Core Principles

### I. Evidence Before Conclusion

任何净值、估值、重仓或策略结果都必须带有来源、时间语义、覆盖范围和数据状态。数据不足时返回 `insufficient`，不使用演示数据、合成数字或无来源文本填补空缺。

### II. Separate Data Semantics

正式历史净值、盘中估值、公开披露重仓和本地缓存必须保持不同字段与状态。盘中估值不得替代正式净值参与历史回测，缓存不得伪装成实时数据。

### III. Reproducible Research

策略研究必须记录时间切分、训练区间、测试区间、样本量、基线、指标和限制。测试集只用于样本外验收，不用于反复调参后重新包装结论；样本不足时拒绝输出策略结论。

### IV. Explicit Degradation

数据链路按主源、声明的备用源、经校验的缓存、数据不足依次降级。每次降级都记录来源、有效行数、时间戳和失败原因，调用方必须能向用户解释当前状态。

### V. Safe Product Boundary

本项目提供数据质量和研究参考实现，不执行交易、不保存账户凭证、不绕过第三方接口限制，也不把模型生成文本当作投资建议。AI 只能解释结构化证据，不能越过数据状态和风险边界生成确定性结论。

## Quality Gates

- 新数据适配器必须有字段校验和异常测试。
- 新策略必须有独立基线与样本外验证。
- 远程 API 失败、空响应、字段变化和覆盖不足必须有回归测试。
- 每次提交必须记录实际运行的测试命令和结果。

## Governance

本宪章约束后续 Spec Kit 的规范、计划、任务、实现与收敛；复杂度和例外必须在计划中说明理由。若与真实代码或数据证据冲突，以可复现证据为准，并更新相关制品。
