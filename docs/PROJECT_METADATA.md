# 聚势基金投研项目元信息

## 项目定位

这是“聚势”基金投研与持仓管理产品的数据质量、降级链和样本外研究参考层。仓库聚焦可验证的底层能力，不保存用户持仓截图或第三方账户凭证，也不提供自动交易。

## 推荐仓库标签

```text
fund-research
financial-data-quality
fallback-chain
out-of-sample
backtesting
python
data-validation
research-audit
risk-disclosure
```

标签用于帮助检索，不代表项目对收益或数据源稳定性作出承诺。远程 GitHub Topics 需要在仓库设置页人工确认。

## 核心设置说明

- 数据状态：`primary`、`fallback`、`cache`、`insufficient` 表示不同证据等级，前端不得把它们渲染成同一种“实时”。
- 研究边界：历史正式净值用于研究；盘中估值只能作为当日参考；公开重仓信息具有披露期滞后。
- 研究验证：默认按时间切分训练区间和测试区间，测试集只用于一次性验收，不用于反复调参。
- 失败策略：主源异常、空响应、字段变化或覆盖不足时，进入可解释的降级链；全部不足时拒绝策略结论。
- 安全边界：不处理账户登录、不执行交易、不绕过服务商限制。

## 贡献验收

提交必须包含最小复现、测试命令和结果。涉及策略时还需提供基线、时间切分、样本量、指标定义和限制说明；只增加漂亮图表或无法复核的收益数字，不视为有效贡献。
